# Controle-de-Investimentos
Sistema desenvolvido para auxiliar no gerenciamento e acompanhamento de investimentos pessoais, permitindo controle de aportes, rentabilidade, diversificação e evolução patrimonial ao longo do tempo.

📌 Objetivo

O projeto tem como finalidade:

Registrar investimentos em diferentes categorias

Controlar aportes e retiradas

Calcular rentabilidade

Acompanhar evolução do patrimônio

Gerar relatórios e gráficos de desempenho

🚀 Funcionalidades

✅ Cadastro de investimentos (Renda Fixa, Renda Variável, Fundos, Criptomoedas etc.)

✅ Registro de aportes e retiradas

✅ Cálculo automático de:

Rentabilidade mensal

Rentabilidade anual

Rentabilidade total

📈 Exemplo de Uso

O usuário cadastra um investimento:

Tipo: Ações

Valor investido: R$ 5.000

Data: 01/01/2026

O sistema calcula automaticamente:

Valor atualizado

Percentual de ganho/perda
